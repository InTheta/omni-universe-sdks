# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not include API keys, private keys, wallet seeds, broker credentials, or exploitable details in a public issue.

For ordinary non-sensitive bugs, open a GitHub issue with a minimal reproduction and the affected SDK version.

## Supported versions

Security fixes target the latest source release on the default branch. Consumers should use least-privilege credentials, separate funded x402 wallets, explicit payment ceilings, broker-side limits, and human approval for material orders.
